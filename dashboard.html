일자별 방문 추이

하루 단위 흐름입니다. 블로그에 글을 올린 날, 광고를 돌린 날과 겹쳐 보면 어떤 활동이 유입을 만들었는지 보입니다.

유입 채널 — 어디서 들어왔나

방문(세션)이 시작된 출처를 묶은 것입니다. 네이버 검색·블로그·카카오톡처럼 국내 경로를 따로 구분합니다.

유입 사이트 (리퍼러 도메인)

직전에 머물던 실제 주소입니다. 채널보다 한 단계 자세히 볼 때 씁니다.

첫 진입 페이지 (랜딩)

사이트에서 처음 열린 페이지입니다. 블로그 링크가 어느 페이지로 연결돼 있는지 확인할 수 있습니다.

시간대별 방문 (KST)

방문이 몰리는 시간대입니다. 블로그 발행·문자 발송 시간을 잡을 때 참고하세요.

방문 경로 — 들어와서 어디로 움직였나

유입 채널에서 시작해 실제로 이동한 페이지 순서입니다. 같은 경로를 탄 방문을 묶어 많은 순으로 보여줍니다(최대 4단계).

채널별 첫 진입 페이지

어느 경로로 들어온 사람이 어느 페이지에 닿았는지 짝지어 본 표입니다.

많이 본 페이지

기간 내 열람 수 기준입니다.

기기

모바일 비중이 높으면 모바일 화면 기준으로 다듬는 게 우선입니다.

브라우저 · 인앱

카카오톡·네이버 앱 안에서 열린 방문은 따로 표시됩니다(공유 링크로 들어온 경우).

전환 버튼 클릭

전화상담·강의신청·결제 등 실제 행동으로 이어진 클릭 수입니다.

캠페인 (UTM)

링크 뒤에 ?utm_source=... 를 붙여 뿌린 경우에만 집계됩니다.

접속 지역

Cloudflare가 알려주는 국가·시도 단위입니다. IP 주소는 저장하지 않습니다.

집계 방식: 방문(세션)은 30분 무활동 기준으로 끊습니다. 유입 채널·리퍼러는 세션의 첫 페이지 기준이며, 사이트 안에서의 이동은 유입으로 세지 않습니다. 봇·크롤러로 보이는 접속은 제외합니다. 수집 항목에 IP·이름·연락처는 없고, 브라우저에 저장되는 익명 난수 ID만 사용합니다.
데이터가 남는 곳: Cloudflare D1 (events 테이블) · 기본 보관 180일.
