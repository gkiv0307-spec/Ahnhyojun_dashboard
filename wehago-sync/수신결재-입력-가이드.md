# 수신결재 건 → 이체관리 시트 입력 가이드

다른 부서·본사에서 지출결의서를 작성해 우리에게 넘긴 건(수신결재함에 들어온 건)을 이체관리 시트에 옮겨 적는 방법입니다. 결의서는 상대 부서가 쓰므로, 우리는 시트 입력과 지급 준비만 합니다.

## 1. 기본 원칙

- 결의서를 우리가 쓰지 않습니다. 시트 `지출결의서` 칸에는 **`결재`** 를 적습니다.
- 지출결의서 칸 상태값은 아래 다섯 가지입니다.

| 값 | 의미 |
|---|---|
| 필요 | 우리가 직접 결의서를 써야 하는 건 |
| 대기 | 결의서를 임시저장해 둔 건(기안 전) |
| 작성 | 기안까지 끝난 건 |
| 요청 | 다른 팀(부동산팀 등)이 결의서를 쓰는 건 |
| 결재 | 수신결재로 들어온 건(결의서는 상대 부서가 작성) |

- `지급여부` 칸은 비워 둡니다. 실제 송금 후 담당자가 직접 표시합니다.
- 통장, 계좌, 지점 등 모르는 값은 추측해서 넣지 말고 **빈칸으로 두거나 요청자에게 물어봅니다.**

## 2. 시트 칸 채우는 법 (B열부터)

| 칸 | 입력 방법 |
|---|---|
| 지급여부 | 비워 둠 |
| 날짜 | **실제 송금일**. 아직 송금 전이면 입력일. 결의서 제목·발행일·요청일은 비고에 적음 |
| 해당부동산 | 지점·사업장 이름 (목록에서 선택) |
| 통장 | 출금할 통장 (목록에서 선택). 정해지지 않았으면 비워 둠 |
| 받는사람 | **예금주** 이름 (결의서 제목의 이름이 아니라 통장 명의) |
| 금액 | 숫자만 |
| 내용 | 결의서 제목·사유를 짧게 |
| 지급수단 | 보통 `계좌이체` |
| 증빙유형 | 전자세금계산서, 지출결의서, 납부확인서 등 |
| 증빙수취 | 아래 3번 참고 |
| 지출결의서 | `결재` |
| 비고 | 요청일, 특이사항 (예: `요청서 날짜 11/2`) |
| 은행 / 계좌 | 은행명, 계좌번호 (계좌번호 형식은 4번 참고) |

## 3. 증빙수취 판정 기준 (WEHAGO 함 위치로 판단)

- 수신결재함에 **그대로 있으면** → 증빙 **미수취** (`필요`)
- 결재내역함으로 **넘어갔으면** → 적격증빙을 받고 결재까지 끝난 것이므로 **수취완료** (`완료`)
- 비고에 "견적서", "캡처" 같은 문구가 있어도 당시 사유일 뿐이므로, 함 위치를 기준으로 합니다.
- 적격증빙은 세금계산서, 카드영수증, 계산서, 현금영수증입니다. 견적서, 간이영수증, 결제창 캡처는 적격증빙이 아닙니다.

## 4. 계좌번호 표기

- 숫자만 있으면 4자리씩 끊어서 공백으로 구분합니다. 예: `3333307424933` → `3333 3074 2493 3`
- 0으로 시작하는 계좌는 앞의 0이 사라지지 않도록 공백이 들어간 형태로 입력합니다. 예: `0500 0724 0973 83`

## 5. 카톡으로 요청이 올 때 입력 예

요청 원문:

```
26/11/19_양산 이그니스 호텔 자재비_575,740
기업은행 41309442304045 (인테리어패밀리)
575,740 원
양산 인테리어
```

시트 입력:

| 칸 | 값 |
|---|---|
| 날짜 | 입력일(송금 전) |
| 해당부동산 | 스테이레브소유 양산점 |
| 통장 | 옆커폰본사통장 (당분간 양산 건은 본사통장에서 출금) |
| 받는사람 | 인테리어패밀리 |
| 금액 | 575740 |
| 내용 | 양산 이그니스 호텔 자재비 |
| 지급수단 | 계좌이체 |
| 지출결의서 | 결재 |
| 은행 / 계좌 | 기업 / 4130 9442 3040 45 |

## 6. 입력 전 확인

1. 시트 맨 아래 행을 다시 읽습니다. 다른 사람이 미리 입력해 둔 행이 있을 수 있습니다.
2. 이미 같은 건이 있는지(받는사람 + 금액) 검색합니다. 중복 입력을 막기 위해서입니다.
3. 기존 행을 고칠 때는 받는사람과 금액이 맞는 행인지 확인한 뒤에 고칩니다.
4. 입력 후 날짜, 금액, 계좌가 제대로 들어갔는지 눈으로 다시 확인합니다. 날짜 칸이 비어 저장되는 경우가 드물게 있습니다.

## 7. Claude에게 시킬 때 (선택)

요청 원문을 그대로 붙여넣고 "시트에 입력해줘"라고 하면 됩니다. 아래 규칙을 먼저 알려 주면 정확합니다.

- 새 건은 이번 달 탭에 입력
- 지급여부는 비움
- 지출결의서 칸은 `결재`
- 통장, 계좌, 지점은 모르면 비워 둘 것 (추측 금지)
- 날짜는 송금일(송금 전이면 입력일)

시트 쓰기용 연동 설정(Apps Script 웹앱의 주소와 토큰)은 개인별 비밀 정보라 이 문서에 넣지 않았습니다. 필요하면 시트 관리자에게 따로 받으세요.
