## 순서

1. **새 계정 준비**(대리님): Google Drive·Google Sheets 커넥터(gkiv0307), GitHub 앱 저장소 접근, (선택) PlayMCP.
2. **새 계정 세션**: 저장소 연결 → CLAUDE.md 자동 로드. 환경 생성.
3. **데이터 확정**(옛 대시보드, PC 크롬): 열어서 저장 성공 확인(Drive 백업 폴더에 새 `ahj_dashboard_snapshot.json.gz` 생김) → 백업 화면 "⬇ 데이터 내보내기 (JSON)" 로 전체 state 저장(압축 아님, 전부 들어 있음).
4. **새 대시보드 발행** → PC 크롬에서 새 URL 열기 → Drive 스냅샷 자동 수신 → 백업 화면 "⬆ 데이터 가져오기" 로 3의 JSON 넣기(압축본 손실 복구) → 홈 건수(학생·거래·경매·DB·블로그) 옛 화면과 대조 → 저장 성공(Drive 새 스냅샷) 확인.
5. **루틴 5개 재생성** → 첫 실행 확인 → 옛 루틴 끄기.
6. **현황판**: 빌드 세션에 원본 보존 요청 → 새 계정에서 발행 → "권리분석보내기" 가 Drive 청크로 대시보드에 들어오는지 확인.
7. **옛 계정**: 아티팩트는 당분간 유지(링크 유입), 루틴만 비활성화. 카톡·메모 링크 갱신.
