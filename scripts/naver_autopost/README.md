# 네이버 블로그 반자동 발행 (대리님 PC용)

대시보드의 **발행대기** 글을 네이버 공식블로그(`ykphone_edu`)에 올리고, 올린 결과를 대시보드에 되돌려 주는 스크립트다.
비밀번호는 저장하지 않는다. 전용 크롬 프로필에 한 번만 직접 로그인해 두면 그 상태가 유지된다.

## 1. 처음 한 번 설정 (PC, 10분)

1. **Python 3.11 이상** 설치 (python.org, 설치 때 "Add python to PATH" 체크).
2. **Google Drive 데스크톱** 설치 → 로그인 → "안효준 대시보드 백업" 폴더가 탐색기에 보이는지 확인
   (보통 `G:\내 드라이브\안효준 대시보드 백업`). 이 폴더에 `ahj_dashboard_snapshot.json.gz` 가 있어야 한다.
3. 이 폴더(`scripts/naver_autopost`)를 PC로 복사한다. 명령 프롬프트를 이 폴더에서 열고:
   ```
   pip install -r requirements.txt
   python naver_autopost.py --list
   ```
   처음 실행하면 `config.json` 이 생긴다. 메모장으로 열어 `drive_backup_dir` 을 실제 경로로 고친다(`\` 는 `\\` 로 두 번).
4. 로그인 한 번:
   ```
   python naver_autopost.py --login
   ```
   크롬이 뜨면 네이버에 직접 로그인("로그인 상태 유지" 체크). 확인되면 창이 저절로 닫힌다.
5. 화면 확인(발행 안 함):
   ```
   python naver_autopost.py --dry-run
   ```
   글쓰기 화면에 제목·본문이 들어간 모양을 보고, 이상하면 여기 세션에 `dry_run_editor.png` 를 보내 준다.
   네이버 에디터 구조가 바뀌면 선택자를 고쳐야 할 수 있다.

## 2. 평소 쓰는 법

- 한 건 올리기: `python naver_autopost.py` (오래된 발행대기 글부터 1건)
- 특정 글: `python naver_autopost.py --id blog-2026-08-27-02`
- 여러 건: `python naver_autopost.py --limit 2` (사이에 1.5~3분 쉰다)
- 올린 글은 `posted_state.json` 에 기록되고, Drive 폴더에 `ahj_blog_chunk_<날짜>-verify-autopost-<시각>.json` 이 생긴다.
  대시보드를 열면 그 글이 **발행완료 + 주소** 로 바뀌고 KPI 에 잡힌다.

## 3. 매일 자동으로 돌리기 (선택)

Windows 작업 스케줄러 → 기본 작업 만들기 → 매일 09:00 → 프로그램 `run_autopost.bat` (시작 위치 = 이 폴더).
PC가 켜져 있고 로그인돼 있어야 하며, 크롬 창이 뜬 채로 돈다. 로그는 `autopost.log`.
하루 1건이 기본(`config.json` 의 `posts_per_run`). 갑자기 여러 건을 쏟아 내지 않는 게 안전하다.

## 4. 알아 둘 것

- **캡차·2단계 인증·로그인 화면이 뜨면 멈춘다.** 우회하지 않는다. `--login` 으로 다시 로그인하면 된다.
- 네이버는 자동 게시를 약관으로 막고 있어 블로그 저품질·계정 제한 위험이 있다(대리님이 알고 결정한 것, 2026-09-22).
  줄이는 방법: 하루 1~2건, 사람이 보는 앞에서, 전용 프로필 하나로만, 다른 계정으로 돌리지 않기.
- 본문은 대시보드 마크다운을 소제목·목록이 살아 있는 형태로 붙여넣는다. 붙여넣기가 안 먹으면 한 줄씩 타이핑한다(느리지만 된다).
- 첫 줄 `메타디스크립션:` 은 접두사를 떼고 첫 문단(기울임)으로 넣는다. 해시태그(`#…`)는 발행창의 태그로도 넣는다.
- 사진·썸네일은 넣지 않는다. 필요하면 발행 뒤 네이버에서 직접 붙인다.
- 스크립트가 올린 글도 07시·20시 루틴의 RSS 확인이 다시 한 번 대조한다(주소가 같으면 중복되지 않는다).
