# 지점별 리뷰어 관리 프로그램

리뷰노트 체험단 운영용 관리 도구입니다. 지점별 선정 리뷰어 명단, 예약 일정, 예약 상태,
방문 완료 여부, 리뷰 등록 여부를 한 화면에서 관리하고, 리뷰어에게 보낼 공유용 일정표를
이미지로 내보낼 수 있습니다.

## 실행 방법

두 가지로 쓸 수 있고, 기능은 같은 코드에서 나옵니다.

### 1) 발행된 링크 (바로 보기)

https://claude.ai/code/artifact/55be07f9-1f4b-4449-b910-7efedabe9a9f

설치 없이 링크만 열면 됩니다. 기본은 비공개이며, 페이지의 공유 메뉴에서 팀에 공개할 수 있습니다.
다만 이 화면은 브라우저 보안 정책상 두 가지가 다릅니다.

- **엑셀(.xlsx) 저장이 허용되지 않아 CSV 로 저장됩니다.** (엑셀에서 그대로 열립니다)
  버튼 이름도 `전체 데이터 CSV` 처럼 실제 저장되는 형식으로 바뀝니다.
- **작업 내용이 저장되지 않을 수 있습니다.** 저장이 막힌 경우 상단에 안내가 뜨며,
  이때는 작업 후 `JSON 백업` 을 받아두어야 합니다.
- 공유용 일정표 PNG/JPG 저장과 JSON 백업은 정상 동작합니다. 저장할 때마다 확인 창이 한 번 뜹니다.

### 팀 공유 저장 (링크를 가진 사람이 같은 데이터를 봄)

발행된 링크에서는 상단에 **팀에 공유 저장** 버튼이 있습니다.

1. 담당자가 명단을 올리고 예약 상태를 정리합니다. (이 단계까지는 내 브라우저에만 있습니다)
2. **팀에 공유 저장** 을 누르면 지금 내용이 페이지 자체에 저장되어 새 버전으로 발행됩니다.
3. 이후 링크를 열고 비밀번호를 넣은 사람은 **같은 명단·예약 현황** 을 보게 됩니다.

- 저장하지 않은 편집이 있으면 상단에 `저장 안 된 변경 있음` 이 뜹니다. 저장 후에는 `공유본 08-18 07:06` 처럼 마지막 저장 시각이 보입니다.
- 저장 권한이 없는 팀원은 `보기 전용` 으로 표시되고 저장 버튼이 사라집니다. 보기·검색·일정표 이미지 저장은 그대로 됩니다.
- 저장하면 열려 있는 모든 화면이 최신 버전으로 새로 불립니다. 그래서 편집할 때마다가 아니라 **정리가 끝났을 때 한 번** 누르는 방식입니다.
- 두 사람이 동시에 저장하면 나중 사람은 "다른 사람이 먼저 저장했습니다" 안내를 받고 최신본을 다시 받습니다.

리뷰어에게는 자기 지점 일정만 보내야 하므로, 공유용 일정표 위의 **지점 탭**으로 지점을 골라
보거나 **지점별 이미지 일괄 저장**으로 지점마다 따로 내보낼 수 있습니다.
탭 옆 숫자는 선택한 기간에 남아 있는 예약 가능한 시간대 수입니다.

**공유 데이터는 비밀번호로 암호화됩니다.** 명단은 페이지 안에 암호문으로 들어가고,
푸는 키는 비밀번호에서 그때그때 만들어집니다. 그래서 링크만 있고 비밀번호를 모르면
소스를 열어봐도 이름·연락처를 읽을 수 없습니다. 반대로 **비밀번호를 바꾸면 이전에
저장한 공유본은 열리지 않으므로**, 비밀번호를 바꿀 때는 바꾼 뒤 한 번 더 공유 저장을 해야 합니다.

### 비밀번호 잠금

두 버전 모두 열면 먼저 비밀번호를 묻습니다. 비밀번호를 아는 사람만 화면을 볼 수 있습니다.

- 비밀번호 **원문은 파일 어디에도 저장하지 않습니다.** 무작위 솔트와
  PBKDF2-HMAC-SHA256(210,000회) 해시만 심어두고 입력값을 같은 방식으로 늘려 비교하므로,
  소스를 열어봐도 비밀번호를 알아낼 수 없습니다.
- 5회 틀리면 30초 동안 잠깁니다.
- `이 브라우저에서 12시간 동안 기억` 을 켜면 그 브라우저에서는 다시 묻지 않습니다.
  공용 PC에서는 체크를 풀고, 자리를 뜰 때 상단의 **잠그기** 를 누르세요.

**비밀번호 바꾸기**

```
python3 set-password.py '새비밀번호'     # 인자 없이 실행하면 화면에 안 보이게 입력받습니다
```

`assets/lock.js` 의 해시를 갱신하고 `dashboard.html` 을 다시 만듭니다.
발행된 링크에도 반영하려면 그 파일을 다시 발행해야 합니다.

**이 잠금이 지켜주는 것과 못 지켜주는 것**

| 상황 | 결과 |
|---|---|
| 링크를 받았지만 비밀번호를 모르는 사람 | 화면을 볼 수 없음 ✅ |
| 공용 PC에서 열어둔 탭을 다른 사람이 봄 | `잠그기` 를 눌러 뒀다면 막힘 ✅ |
| 자바스크립트를 끄고 열기 | 본문이 나오지 않음 ✅ |
| 링크를 가진 사람이 개발자 도구로 코드를 고쳐서 우회 | **막지 못함** ⚠ |

마지막 항목 때문에, 이 비밀번호는 **두 번째 잠금장치**로만 쓰세요.
실제 접근 제어는 **아티팩트 공유 범위**(비공개로 두거나 필요한 사람에게만 공유)로 하고,
비밀번호는 링크가 실수로 퍼졌을 때를 대비한 장치로 보는 것이 맞습니다.
비밀번호는 단체 대화방에 올리지 말고 필요한 사람에게 따로 전달하세요.

### 2) 로컬 실행 (전체 기능)

엑셀(.xlsx) 저장과 자동 저장이 모두 필요하면 이쪽을 쓰세요. 설치·빌드·서버가 필요 없습니다.

- **가장 간단한 방법**: `reviewer/index.html` 파일을 브라우저(크롬·엣지 권장)로 열기
- **로컬 서버로 실행**(권장): 저장소 루트에서
  ```
  python3 -m http.server 8080
  ```
  실행 후 `http://localhost:8080/reviewer/` 접속
  (저장소에 포함된 `_local-preview-server.ps1` 을 사용해도 됩니다)

처음 열면 **빈 상태**로 시작합니다. 지점을 추가하거나 명단 파일을 올리면 됩니다.
(명단 파일의 지점명은 가져오기 후 "새 지점으로 추가"로 바로 등록할 수 있습니다)

기능을 먼저 둘러보고 싶다면 `설정 → 데이터 관리 → 둘러보기용 샘플 불러오기` 를 누르세요.
샘플은 예시용 가짜 자료이며, 저장된 샘플이 남아 있으면 다음에 열 때 자동으로 비웁니다.
직접 입력하거나 파일에서 가져온 자료는 그대로 유지됩니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| **대시보드** | 지점별 전체 명단 수, 예약전/예약요청/예약확정/방문완료/취소 인원, 잔여 예약 가능 수, 임박한 예약 |
| **리뷰어 명단** | CSV·엑셀 업로드, 엑셀처럼 편집 가능한 표, 지점/상태 필터·검색·정렬 |
| **예약 현황** | 지점별 날짜 × 시간대 보드(가능 n / 마감), 시간대별 배정·상태 변경 |
| **공유용 일정표** | 지점 탭으로 지점별 일정 확인, 개인정보 없는 미리보기, PNG/JPG 저장, 지점별 이미지 일괄 저장 |
| **설정** | 지점 추가·수정·삭제, 예약 가능 날짜/시간대, 시간당 인원, 데이터 백업·복원 |

상단 바의 **지점 · 기간 · 검색**은 모든 탭에 공통 적용됩니다.

## 명단 업로드

`리뷰어 명단 → 파일 선택` 또는 드래그 앤 드롭. **CSV(.csv, .tsv)와 엑셀(.xlsx)** 을 지원합니다.

인식하는 열(머리글 이름이 조금 달라도 자동 매칭됩니다):

| 항목 | 인식되는 머리글 예시 |
|---|---|
| 지점명 | 지점명, 지점, 매장명, branch |
| 리뷰어명 | 리뷰어명, 이름, 닉네임, name |
| 계정 URL | 계정 URL, 계정, 블로그, 링크, url |
| 연락처 | 연락처, 전화번호, 휴대폰, phone |
| 주소 | 주소, 거주지 |
| 노출점수 | 노출점수, 점수, score |
| 등급 | 등급, 레벨, grade |
| 일 방문 수 | 일 방문 수, 일방문수, 방문수 |
| 신청메시지 | 신청메시지, 신청내용, 메시지 |
| 메모 | 메모, 비고, 특이사항 |
| (선택) 희망일 · 희망시간 · 예약상태 · 리뷰등록 | 희망일, 예약일 / 희망시간, 예약시간 / 예약상태, 상태 / 리뷰등록 |

- 머리글 위에 안내문 등 잡음 행이 있어도 머리글 행을 자동으로 찾습니다.
- `2026-08-20`, `8/20`, `8월 20일`, 엑셀 날짜 셀 → 모두 `2026-08-20` 으로 정규화합니다.
- `오후 5시`, `17시`, `5:00 PM` → `17:00` 으로 정규화합니다.
- `확정`, `완료` 같은 축약 표기도 `예약확정`, `방문완료` 로 정규화합니다.
- 가져오기 전에 **미리보기**가 뜨며, `기존 명단에 추가` 또는 `전체 교체` 를 선택합니다.

샘플 파일: `sample/리뷰어_명단_샘플.csv`, 빈 양식: `sample/업로드_양식.csv`
(앱 안의 `샘플 양식 CSV 받기` 버튼으로도 받을 수 있습니다)

## 예약 인원 계산 규칙

- 예약상태는 **예약전 · 예약요청 · 예약확정 · 방문완료 · 취소** 5가지입니다.
- 이 중 **예약요청 · 예약확정 · 방문완료** 만 예약 인원에 반영합니다. (예약전·취소는 자리를 차지하지 않음)
- 잔여 인원 = 해당 지점·날짜·시간대의 정원 − 반영 대상 인원
- 잔여 0명이면 **마감**(빨강), 남아 있으면 **가능 n**(초록)으로 표시합니다.
- 정원은 지점별 `시간당 기본 인원` 을 따르며, 특정 날짜·시간대만 `설정 → 시간대별 인원` 에서 따로 지정할 수 있습니다.
- 정원을 넘겨 배정된 경우 **초과 n** 으로 빨갛게 경고합니다.

상태별 색상: 가능 초록 / 마감 빨강 / 예약요청 노랑 / 예약확정 파랑 / 방문완료 진한 초록 / 취소 연한 회색

## 미매칭 지점

업로드한 파일의 지점명이 등록된 지점과 다르면 저장은 하되 **미매칭**으로 표시하고,
상단에 확인 배너를 띄웁니다. `지점 매칭하기` 에서 기존 지점에 연결하거나 새 지점으로 추가할 수 있습니다.
(공백·대소문자 차이는 자동으로 같은 지점으로 인식합니다)

## 내보내기

| 버튼 | 결과 |
|---|---|
| 대시보드 → `전체 엑셀 다운로드` | 요약 / 리뷰어명단 / 예약현황 / 지점설정 4개 시트 `.xlsx` |
| 명단 → `현재 목록 엑셀` | 화면에 보이는 필터 결과만 `.xlsx` |
| 명단 → `지점별 파일 저장` | 지점별 개별 파일 또는 지점별 시트 한 파일 |
| 예약 현황 → `예약 현황 엑셀` | 시간대별 정원·예약·잔여 + 예약 목록 |
| 공유용 일정표 → `PNG 저장` / `JPG 저장` | 지금 보고 있는 지점(또는 전체)의 일정표 이미지 |
| 공유용 일정표 → `지점별 이미지 일괄 저장` | 지점마다 그 지점 일정만 담은 이미지를 하나씩 저장 |
| 설정 → `JSON 백업` | 전체 데이터 백업(다른 PC로 이동 시 사용) |

엑셀 파일은 외부 라이브러리 없이 브라우저에서 직접 생성하므로 인터넷 연결 없이도 동작합니다.

## 개인정보 취급

- **공유용 일정표에는 지점명 · 날짜 · 시간대 · 가능 인원 · 마감 여부만 들어갑니다.**
  리뷰어명·연락처·주소·계정 URL·신청메시지는 화면에도 이미지에도 포함되지 않습니다.
- 상단 바의 `개인정보 가리기` 를 켜면 관리자 화면에서도 연락처·주소·계정·신청메시지가 마스킹됩니다.
  (화면 공유·회의 중 사용)
- **업로드한 파일의 내용은 데이터로만 해석합니다.** 파일 안에 지시문처럼 보이는 문장이 있어도
  프로그램 동작 지시로 실행하지 않으며, 모든 값은 텍스트로만 저장·표시됩니다.
- CSV로 내보낼 때 `=`, `+`, `-`, `@` 로 시작하는 값 앞에 `'` 를 붙여 수식으로 실행되지 않게 합니다.

## 데이터 저장 위치

모든 데이터는 **사용 중인 브라우저의 localStorage** 에만 저장됩니다. 서버로 전송되지 않습니다.

- 다른 PC·브라우저에서 이어서 작업하려면 `설정 → JSON 백업` 후 다른 쪽에서 `JSON 백업 복원`
- 브라우저 데이터를 지우면 명단도 함께 사라집니다. 중요한 작업 후에는 엑셀/JSON으로 백업하세요.
- 공용 PC에서 사용했다면 작업 후 `설정 → 전체 초기화` 를 권장합니다.
- 내 브라우저에 남는 작업본은 암호화하지 않습니다. 반면 **팀에 공유 저장한 데이터는
  비밀번호로 암호화**되어 페이지에 들어갑니다.
- 공유 저장을 하면 개인정보가 페이지에 담겨 링크를 가진 사람에게 전달됩니다.
  꼭 필요한 사람에게만 링크와 비밀번호를 주세요.

```
reviewer/
├── index.html              로컬 실행용 화면 구조
├── assets/
│   ├── lock.js             비밀번호 잠금(PBKDF2 해시 검증 + 암복호화 키 유도)
│   ├── share.js            팀 공유 저장(암호화 · 페이지 재구성 · 발행)
│   ├── app.css             스타일(반응형 · 라이트/다크 · 상태별 색상)
│   ├── app.js              화면 렌더링 · 편집 · 내보내기 · 일정표 이미지 생성
│   ├── store.js            상태 관리 · 예약 계산 · CSV 파싱 · 지점 매칭
│   └── xlsx-lite.js        의존성 없는 XLSX 읽기/쓰기(ZIP + 시트 XML)
├── set-password.py         비밀번호 설정/변경
├── build-dashboard.py      위 파일들을 dashboard.html 한 장으로 합치는 스크립트
├── dashboard.html          발행용 단일 파일 (생성물 — 직접 고치지 마세요)
└── sample/                 업로드용 샘플 CSV
```

`assets/` 안의 파일을 고친 뒤에는 `python3 build-dashboard.py` 를 실행해 `dashboard.html` 을
다시 만들어야 발행된 링크에도 반영됩니다. 두 버전은 같은 코드를 공유하므로 동작이 갈라지지 않습니다.
(`dashboard.html` 은 발행 시 `<!doctype>` 등이 씌워지므로 파일을 직접 열면 레이아웃이 깨집니다 —
로컬에서는 `index.html` 을 여세요.)

## 화면 테마

라이트/다크를 모두 지원하며 보는 사람의 설정을 따릅니다.
단, **공유용 일정표 카드는 항상 밝은 색으로 고정**됩니다 — 내보내는 이미지와 화면이
달라 보이면 안 되기 때문입니다.

## 브라우저 요구사항

크롬 · 엣지 · 사파리 16.4 이상 · 파이어폭스 113 이상.
`.xlsx` 업로드는 브라우저의 `DecompressionStream` 을 사용하므로, 구형 브라우저에서는
CSV로 저장해 업로드하세요. 구형 `.xls` 형식은 지원하지 않습니다.
