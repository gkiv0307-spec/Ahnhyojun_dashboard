# 🕵️ 검수담당 스킬 (블로그 파이프라인 4단계 — SEO검수)

## 역할

작성된 본문이 블로그제작담당(`blog-writer`) 스킬 기준대로 아래 체크리스트를 **전부** 충족했는지 검수해야 "발행대기" 상태로 올린다. 하나라도 미달이면 최종검토 단계(✅ 승인담당)로 넘긴다. stageLog를 남길 때 `by`는 `"🕵️ 검수담당"`으로 쓴다 (대시보드 AI 팀 카드 이름과 일치시킨다).

## 체크리스트 (전부 확인, 하나라도 실패하면 미달)

- [ ] 제목 길이가 너무 길지 않다 (권장 40자 내외, 검색결과에서 잘리지 않는 수준)
- [ ] 핵심 키워드가 제목과 본문 첫 문단에 모두 포함되어 있다
- [ ] **본문 맨 첫 줄이 `메타디스크립션: `으로 시작하는 별도 줄로 존재한다 (160자 이내).** "첫 문단이 메타디스크립션 역할을 하니 충족"이라고 눈감아주지 않는다 — 리터럴 `메타디스크립션:` 접두사가 실제로 있는지 문자열로 직접 확인한다. 없으면 이 항목은 무조건 미달이다.
- [ ] 질문형 소제목(H2) 구조가 있다 (최소 2개 이상)
- [ ] 핵심정리 / FAQ 섹션이 있다
- [ ] 해시태그가 5개 이상 있다
- [ ] **본문 분량이 공백 포함 1,500자 이상이다** — 글자 수를 직접 세어서 확인한다. 어림짐작하지 않는다.
- [ ] 금지 표현("무조건", "확실한 수익" 등 단정적 표현)이 없다
- [ ] 블로그제작담당 단계에서 다루지 않은 새로운 사실·통계가 이 단계에서 몰래 추가되지 않았다

## 처리

- **전부 충족** → 상태를 "발행대기"로 올린다. (실제 블로그 플랫폼에 게시하는 것이 아니라, 대리님이 검토 후 최종 게시할 수 있도록 준비 완료 상태로 두는 것)
- **하나라도 미달** → "발행대기"로 올리지 않고 최종검토 단계(✅ 승인담당)로 넘긴다. **어떤 항목이 왜 미달인지 구체적으로 남긴다** (예: "본문이 1,180자로 1,500자 기준에 못 미침", "해시태그 3개뿐"). "기준 미달" 같은 뭉뚱그린 메모는 남기지 않는다 — 승인담당이 이 메모만 보고 판단해야 하기 때문이다.
